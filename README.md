# E-Commerce Management System

A console-based E-Commerce Management System built using Python (OOPs Concept) and MySQL for product and order management.

### Description
This project allows users to browse products without login and provides full shopping features after registration, similar to real e-commerce platforms like Amazon/Flipkart.

### Features

**1. Browse Catalog (Guest Access)**
   - Display Product Name, Category, Price, Stock
   - No login required to view products

**2. User Registration**
   - Input: Full Name, Email, Password
   - Output: Registration Successful

**3. User Login**
   - Secure login with Email & Password
   - After Login Menu:
     - 1) Browse Catalog
     - 2) Add Item to Cart
     - 3) View Cart
     - 4) Checkout
     - 5) Order History
     - 0) Logout

### Tech Stack
- **Language:** Python
- **Database:** MySQL
- **Concepts Used:** OOPs, Database Connectivity, Exception Handling

### How to Run This Project

1.  **Database Setup:** Import the `ecommerce.sql` file into MySQL Workbench.
2.  **Install Dependency:** `pip install mysql-connector-python`
3.  **Configure Password:** Open the main `ECOMMERCE.py` file and update your MySQL password.
4.  **Run:** `python  ECOMMERCE.py`
